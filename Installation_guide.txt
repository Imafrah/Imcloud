To start the Server on Windows Powershell:

Terminal-1
node C:\server\upload-server\server.js
Terminal-2
caddy run --config C:\server\Caddyfile.txt
Terminal-3
cloudflared tunnel --url http://localhost:80   


Storage location: All uploaded files are physically stored on the computer running IMCLOUD.

Important Notes:
The computer running IMCLOUD is the actual storage server.
Laptop OFF     → IMCLOUD OFFLINE
Node stopped   → API unavailable
Caddy stopped  → Website unavailable
Tunnel stopped → Remote access unavailable
